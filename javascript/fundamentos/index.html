Guia de Fundamentos JavaScript

O que é JavaScript?

  • Linguagem de progamação.

    JavaScript é uma Linguagem usada criar comportamentos dinãmicos, permitindo que páginas reajam a ações do usúario.

  • O cérebro da web

    Enquanto o HTML estrutura e o CSS estiliza, o JavaScript decide o que acontece, quando acontece e por que acontece.

  • Linguagem de alto nível

    Possui sintaxe próxima da linguagem humana e abstrai detalhes complexos como gerenciamento manual de memória.

  • Execução com JIT

    JavaScript utiliza uma execução híbrida: interpretado inicialmente, recompilado dinamicamente pelo JIT (Just-In-Time) com otimizações durante a execução.

  • Onde roda?

    JavaScript roda em qualquer ambiente que possua um motor JavaScript: navegadores (Chrome, Firefox), servidores (Node.js), aplicações mobile e dispositivos IoT.
